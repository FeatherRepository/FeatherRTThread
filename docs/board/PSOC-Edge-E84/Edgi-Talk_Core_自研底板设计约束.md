# 基于 Edgi-Talk_Core 核心板自研底板 — 设计约束清单

> 配套文档：`Edgi-Talk_原理图分析.md`（完整原理图分析，含 BTB 逐针映射与 IO 总表）。
> 本文档只列**约束与接口契约**——自研底板设计时逐条对照。
> 连接器：核心板侧 2× DF40C_80DP（0.4mm）⇔ 底板侧需配 **DF40C_80DS**，叠高 1.5/2.0/2.5/3.0/3.5/4.0mm 可选（原板具体档位以 BOM 为准），**0.3 A/针**。

## 1. 电源接口契约（硬约束）

| BTB 信号 | 方向 | 规格 | 底板要做什么 |
|---|---|---|---|
| **VIN**（CN1 pin 1~5，5 针并联） | 底板→核心板 | **3.0~5.0 V**，主电源 | 必须提供。原板 = VOUT（USB 5V / 电池 SYS 经 OR'ing）；只给 3.3 V 也能工作（在范围内）。电流预算见下 |
| VDDUSB_3V3（CN2 pin 6） | 底板→核心板 | 3.3 V（VDD.USB 范围 3.07~3.63 V） | **用 USB 才供**；不用 USB 就把这针**接地**（E84 要求 VDD.USB 不用时接地，不可悬空） |
| VDD/VDDIO_3V3（CN2 pin 16） | 底板→核心板 | 3.3 V | 核心板上无消费者，自研底板**可悬空** |
| **VDD_1V8**（CN1 pin 76~80，5 针） | **核心板→底板** | 1.8 V（TPS63802 产） | 底板的 1.8 V 外设（传感器/麦偏置/WiFi VDDIO/上拉）可吃它，但**要算进核心板 buck 的负载预算** |
| VREF（CN2 pin 21） | 核心板→底板 | 参考电压输出 | 底板 ADC 采样可用作基准 |
| GND（两连接器各 4+ 针） | — | — | 全部接实 |

- **无上下电时序要求**（E84 特性）。
- **电流预算**：核心板 1.8 V 域 = MCU 满载 IDDD≈74 mA + 存储 + 底板回供负载。按 1.8 V 侧 200 mA、效率 85% 折算，VIN=4.2 V 时输入 ≈100 mA；GPU/NPU 全开按 300 mA 留裕量。5 针 VIN ×0.3 A = 1.5 A，连接器不构成瓶颈。

## 2. 逻辑电平（硬约束）

- **所有 IO 都是 1.8 V，包括 P16/P17**（核心板 VDDIO6 经 R6 0Ω 接了 1.8 V）。底板上的 3.3 V/5 V 外设必须电平转换。
- 原板方案可参考：低速/开漏走 TXS0108E（注意它是弱驱动自动双向，高速不行），SD 卡走 TXS02612 专用转换器。
- VDDIO6 改 3.3 V 理论上可行（去 R6、往 VDD_TEST 注 3.3 V），但属于改核心板 + 底板重设计，不建议走这条路；**要 3.3 V IO 域就直接自研核心板或用官方 SoM**。

### 2.1 折中方案：VDDIO6 电平交给底板选（改核心板）

核心板上 VDDIO_6 的供电链是 `VDDIO_6 ← VDD_TEST ← R6 0Ω ← VDD/VDDIO_1V8`，而 BTB 的 **CN2 pin 16（VDD/VDDIO_3V3）在核心板上是空网（无消费者）**。因此可以：

1. **核心板改动**：拆掉 R6，把 VDD_TEST 改接到 CN2 pin 16（原设计没有 0Ω 选焊盘，需飞线或改板重投；改板时可顺便做成 R6/新焊盘二选一选位，兼容两种底板）
2. **底板侧**：CN2 pin 16 用 0Ω/跳线选 **1.8 V 或 3.3 V**（底板上两路都有：核心板回供的 VDD_1V8、底板自产的 3.3 V buck）——VDDIO6 电平由底板决定

注意点：

- 该针**必须始终供电**（P16/P17 上有信号，IO 域不能悬空/浮电）；单针 0.3 A 额定对 IO 域供电足够，VDDIO_6 的去耦 C41/C42 在核心板 VDD_TEST 上、改接后依然有效
- 核心板的 BOOT 上拉电阻网络挂在 VDD_TEST 上（sheet 10，R95/R96），会跟随该电平——自洽（P17.6 本就属 VDDIO6 域）
- 选 3.3 V 后 P16/P17 全部信号对底板就是 3.3 V 逻辑，底板对应电路（CAN 收发器 VIO、门控 NMOS、触摸 INT/RST 等）直接按 3.3 V 设计，省掉电平转换
- **改过的核心板不能再插回原底板**：原底板 TXS0108E 的 A 侧固定在 1.8 V（VCCA=1.8 V，A 侧信号超 VCCA 不允许），3.3 V 会失配
- VDDIO6=3.3 V 时该域 GPIO 上限 50 MHz（1.8 V 标准 GPIO 是 100 MHz），高速信号别放这域
- 核心板脱离底板单跑时 VDDIO6 无供电——仅在自研底板配套下使用该方案

## 3. 核心板固化、底板改不了的资源

| 资源 | 状态 | 影响 |
|---|---|---|
| 存储 | SMIF 全占用：128Mb QSPI Flash + 128Mb HyperRAM，select0（P5.0）悬空 | **底板无法加 XIP 存储**；扩容只能 SD 卡（SDIO 在 BTB 上）或 SCB SPI（慢、无 XIP） |
| 主时钟 | ECO = **12.288 MHz**（音频友好）固定 | I2S MCK 分频干净；USB HS 也可用（DPLL 分频出） |
| RTC 时钟 | WCO 32.768 kHz 已贴 | RTC/Hibernate 定时直接用 |
| EXT_CLK | P7.4 未引出（核心板留 Y3 24M 焊盘 DNP） | 底板拿不到；要用得改核心板贴 Y3 |
| PDM 麦 ×2 | 已贴核心板（P8.5/P8.6） | 底板可直接用这组数字麦；PDM 总线也过了 BTB，可再挂 |
| AMIC 前端 RC | 反馈/偏置网络在核心板（增益 ≈20 dB 固定） | 底板只能接麦克风本体，**增益和拓扑改不了**；模拟小信号要过 BTB（CN2 pin 1~4），注意布局 |
| 调试 UART | 固定 P6.4~6.7 | 底板引到调试器/排针即可 |

## 4. BTB 上可用的接口（自研底板的资源池）

- **自由 GPIO**：GPIO_0~19（20 个，1.8 V）
- **显示**：MIPI DSI 2-lane（最高 1.5 Gbps/lane）+ DISP_RST/TE/TP 触摸控制（I2C7 在 P13.1/13.2，1.8 V）+ BL_PWM_DISP
- **USB**：DP/DM（HS 480 Mbps，记得配 VDDUSB_3V3）
- **音频**：I2S TX（P21.1/21.2/21.3 + P12.3 FSYNC）→ 外接 codec/功放；PDM 总线；AMIC×2 差分
- **通信**：主 I2C（P8.0/8.1）、I3C、SPI9（P15.0~15.4）、UART×2、CAN0（P16.0/16.1）、SERIAL_INT×4
- **SD 卡**：SDIO 组（P7.0~7.7，1.8 V，卡侧 3.3 V 需 TXS02612 级转换）
- **WiFi/BT 位**：WL_SDIO（P12.0~12.5 + P21.0 CMD）+ BT_UART（P10.0~10.3）+ REG_ON/WAKE 控制组——不贴无线模组可释放为 GPIO（注意 P12.3 与 I2S FSYNC 复用）
- **模拟**：ARD_ADC_3（P15.5，专用 ADC 通道，原板用于电池分压监测）；SPI9 不用时 P15.0~15.4 可让位当 SAR 输入
- **调试**：SWD 全套 + TRACE×5 + XRES_L + BOOT（P17.6，底板做启动源拨码：0=内部 RRAM，1=板上 QSPI）

## 5. 低功耗天花板 ★电池产品最关心的约束

| 项 | 电流 | 说明 |
|---|---|---|
| E84 Hibernate+RTC（外部稳压模式） | ≈5.7 µA @1.8 V | 核心板固定外部稳压模式，拿不到电池模式的 2.2 µA |
| 核心板 TPS63802 静态电流 | **11 µA 典型**（规格书：非开关状态 IQ） | 关掉它（ISD=45 nA）则 1.8 V 断、RTC 停走——不能关 |
| **核心板待机下限** | **≈15~25 µA 级**（含轻载 PFM 损耗） | 对比自研电池模式方案（NPM1300 + VBAT buck）：**~3 µA 级** |

缓解手段只有：底板把自己的 3.3 V/5 V 外设域门控掉（原板 CTRL=P7.2 管 3.3 V buck 的设计可沿用），核心板 1.8 V 必须常开。

**结论：长待机电池产品（如 openhifi 最终形态）不适合直接用这套核心板做产品；它适合作为开发/功能验证平台。** 若产品化必须低功耗，走自研核心板（电池模式 + NPM1300）。

## 6. 机械与工艺

- 2× DF40C_80DP 对 DF40C_80DS，**0.4 mm 细间距**：SMT 钢网/回流焊工艺要求，手焊不可行
- 叠高 1.5~4.0 mm 按结构选择；核心板有 3 个定位孔（H1~H3）
- AMIC 差分对过 BTB：底板侧麦克风走线要短、远离 DSI/USB 高速针区域、包地
- DSI/USB 差分在核心板侧已串 33 Ω，底板侧保证 100 Ω 差分阻抗、等长即可

## 7. 底板最小系统检查单

1. VIN：3.0~5.0 V，≥300 mA 能力，5 针全接
2. VDDUSB_3V3：用 USB 供 3.3 V，不用就把 CN2 pin 6 接地
3. GND 全接；VDD_1V8 回供可用于底板 1.8 V 外设（计入预算）
4. BOOT 拨码/电阻、XRES_L 复位键
5. SWD 排针（或用核心板自带 J1，DNI 件）
6. 1.8 V 逻辑：任何 3.3 V 器件先过电平转换
7. 休眠设计：底板外设电源门控 + 核心板 VIN 常开
