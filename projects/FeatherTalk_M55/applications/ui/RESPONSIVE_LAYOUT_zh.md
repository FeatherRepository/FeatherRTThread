# FeatherTalk 响应式布局设计

FeatherTalk UI 以 480×800 为设计基准，但页面代码不得直接使用该分辨率的固定坐标。启动时 `feathertalk_ui_layout.c` 从 LVGL 默认 Display 读取实际宽高，计算本次 UI 生命周期使用的布局配置。

## 缩放和断点

- 缩放比例取 `min(width / 480, height / 800)`，并限制在 65%～150%，避免极端分辨率产生不可点击的控件或过大的固件字体需求。
- 宽度小于 360 像素使用两列 Start Tile；360～639 像素使用三列；640 像素及以上使用四列。
- 宽 Tile 始终跨两列，宽度按 `2 × column + gap` 计算；普通 Tile、间距和页面边距共同严格落入可用宽度。
- 小于 360 像素宽或 560 像素高进入 compact 模式，缩短状态栏品牌和桌面提示文字。
- `width > height` 时记录为 landscape；同一套列宽、flex-grow 和可滚动内容规则适用于横屏启动。
- 当前支持的最低启动几何为 200×240。产品实际板卡仍为 480×800。

## 组件规则

- Status、Navigation、Notification、Alert、页面边距、字体、图标、按钮、列表行、键盘和 Tile 高度全部来自统一布局配置。
- Start 和 All Apps 使用固定标题行加 flex-grow 内容区；内容不足时不制造空白高度，内容过多时只让列表区域垂直滚动。
- Settings 的 5 个色块以及三组偏好按钮使用等宽 flex；Media 使用 `1:2:1` 的上一首、播放、下一首比例。
- Search 键盘不超过可用内容高度的一半，并作为路由根容器的固定底部覆盖层，不参与内容页纵向 flex/滚动；普通页面允许纵向滚动，横向控件始终限制在父容器内容宽度内。
- 24/32/48 三档 A8 图标按当前缩放比例选择最接近的已生成尺寸，不在板端执行模糊缩放。
- 当前字体只从 SDK 已启用的 Montserrat 12/14/16/22 中选择，避免为了大屏布局额外链接整套字体资源。

## 新页面约束

1. 使用 `ft_layout_px()` 转换设计尺寸，或直接使用 `lv_pct()`、flex-grow 和 `LV_SIZE_CONTENT`。
2. 字体通过 `ft_layout_font()` 获取，图标尺寸通过 `ft_layout_icon_size()` 获取。
3. 多个同级按钮设置 width=0 后使用 flex-grow 分配，不按像素写死总宽度。
4. 可增长内容必须放入 flex-grow 或可滚动容器，禁止写死页面剩余高度。
5. 新增交互控件必须进入自动测试；`ft_layout_control_fits()` 会拒绝零尺寸或宽于父容器的控件。

## 自动验证

固件自测会先计算并检查 240×320、320×480、480×800、720×1280 和 800×480 五种布局配置，再在真实 Display 上对每个被点击控件执行几何检查。`feather_ui_status` 输出实际缩放、compact/landscape、Tile 列宽、栏高和键盘高度，便于板测追踪。
